# 프런트엔드 설정 및 실행

1. 백엔드를 먼저 실행합니다.

   [백엔드 실행 방법](../backend/README.md)

2. `frontend/.env.local`을 생성합니다.

   ```dotenv
   VITE_API_MODE=api
   VITE_API_BASE_URL=/api/v1
   API_PROXY_TARGET=http://localhost:8080
   ```

3. 의존성을 설치합니다.

   ```sh
   cd frontend
   npm ci
   ```

4. 프런트엔드를 실행합니다.

   ```sh
   npm run dev -- --port 5173
   ```

5. 브라우저에서 접속합니다.

   [http://127.0.0.1:5173](http://127.0.0.1:5173)

6. **우리길 AI 고객센터**를 누르고 **궁금한 내용을 입력해 주세요**에 아래 문장을 입력합니다.

   > 월급날이 25일로 바뀌어서, 엄마한테 매달 20일에 생활비 보내던 걸 26일로 바꾸고 싶어.

7. **AI로 상담 방법 찾기**를 누르고 화면의 추가 질문에 답변합니다.

> 현재 프로토타입은 테스트 가능한 시나리오가 제한되어 있습니다. 위 문장은 검증된 자동이체 날짜 변경 시나리오입니다.

8. 종료하려면 프런트엔드 터미널에서 `Ctrl+C`를 누릅니다.
